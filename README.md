# tidyline

Offline, read-only audit and health report for your Things 3 database on macOS.

Status: early development. Not usable yet.

tidyline is an independent project. It is not affiliated with, endorsed by or
sponsored by Cultured Code. "Things" is a trademark of Cultured Code GmbH & Co. KG.

Exports produced by this tool contain your personal task data. Do not share
them publicly without anonymising them first.
